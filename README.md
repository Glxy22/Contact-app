# Contact App

A full-stack contact form application built with Next.js, MongoDB, and Nodemailer. Visitors can submit inquiries through the form, submissions are stored in a database, and the admin receives an instant email notification for every submission.

---

## Features

- Contact form with client-side validation
- Submissions stored in MongoDB
- Instant email notification to admin on every form submission
- CI pipeline with GitHub Actions on every pull request

---

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | Next.js 16, React 19, Tailwind CSS |
| Backend | Next.js API Routes |
| Database | MongoDB |
| Email | Nodemailer + Gmail |
| CI | GitHub Actions |
